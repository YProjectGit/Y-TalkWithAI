# 8. ImageToImage — 画像＋指示 → 画像変換（概要）

> **現状**: フォルダと概要のみ。シーン・スクリプトは未実装です。  
> シリーズ全体の位置づけ → [Docs/demo-series-overview.md](../../Docs/demo-series-overview.md)

## このデモで学べること（予定）

- 入力画像と短いテキスト指示をセットで送る流れ
- 画像生成／編集 API から変換後の画像を受け取り、表示する流れ
- `7. TextToImage`（テキストだけ）との違い＝**参照画像がある**こと

## 処理の骨格

```text
入力画像 ＋ 指示テキスト
  → 画像変換 / 編集（Image）
  → 画面に表示（変換後）
```

入力画像の取り方は、教材では次のいずれか（実装時に1つに絞る想定）です。

- ファイル／用意済みテクスチャ
- WebCam の1フレーム（`5. VisionToSpeech` と同型）
- 画面キャプチャ（`6. ScreenToSpeech` と同型）

## 事前準備（実装後に使う想定）

1. APIキーの取得と `Assets/Common/APIKey.txt` への保管  
   → [Docs/gemini-ai-studio-setup.md](../../Docs/gemini-ai-studio-setup.md)
2. 変換元になる画像が用意できること
3. 利用する画像編集モデル／エンドポイントがキーで使えること（実装時に確認）

## 主要スクリプトの読み方（実装後）

入口スクリプトを上から読む想定の流れです。

1. APIキー読込・入力画像の取得
2. 指示テキストと画像をリクエストに載せる
3. 変換後画像の受信
4. Before / After を並べて表示（教材向けに差分が分かりやすいとよい）
5.（教材向け）Status / 指示文 / 生データの可視化

## 改変のヒント（実装後に触るとよい箇所）

- 指示文（「線画にする」「背景だけ変える」など）
- 入力画像の解像度
- Before / After の見せ方

## まだやらないこと

- テキストだけから新規生成（→ `7. TextToImage`）
- 画像を解釈して声で返す（→ `5. VisionToSpeech` / `6. ScreenToSpeech`）
