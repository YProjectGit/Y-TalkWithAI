# 3. SpeechToSpeech — マイク音声 → 音声で返答（概要）

> **現状**: フォルダと概要のみ。シーン・スクリプトは未実装です。  
> シリーズ全体の位置づけ → [Docs/demo-series-overview.md](../../Docs/demo-series-overview.md)

## このデモで学べること（予定）

- マイクから音声を録り、STT（Speech-to-Text）でテキストにする流れ
- そのテキストを LLM に渡し、返答を TTS で音声にして再生する流れ
- 「声で話して声で返る」一気通貫のパイプライン

## 処理の骨格

```text
マイク入力（音声）
  → STT（ユーザー発話テキスト）
  → LLM（返答テキスト）
  → TTS（音声データ）
  → スピーカー再生
```

`2. TextToSpeech` の前段に **録音と STT** が付いた形です。LLM〜TTS〜再生は 2 と同じ発想で追えます。

## 主要スクリプトの読み方（実装後）

入口スクリプトを上から読む想定の流れです。

1. APIキー読込・マイク初期化
2. 録音開始 / 停止（または押し話し）
3. STT で発話テキスト化・表示
4. LLM → 返答テキスト
5. TTS → 再生
6.（教材向け）各段の Status / 中間テキストの可視化

## 改変のヒント（実装後に触るとよい箇所）

- 押し話し（押している間だけ録音）か、自動エンドポイントか
- STT / LLM / TTS のモデルや言語設定
- 認識テキストを画面に出して、誤認識を学生が気づけるようにする
