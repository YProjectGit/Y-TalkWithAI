## このデモで学べること（予定）

- マイクから音声を録り、STT（Speech-to-Text）でテキストにする流れ
- そのテキストを LLM に渡し、返答テキストを得る流れ（出力は `1A.TextToText` と同型）
- 「声で聞いて、画面には文字で返る」パイプライン

## 処理の骨格

```text
マイク入力（音声）
  → STT（ユーザー発話テキスト）
  → LLM（返答テキスト）
  → 画面表示
```

`1A.TextToText` の前段に **録音と STT** が付いた形です。TTS（声で返す）はまだやりません。

## 事前準備（実装後に使う想定）
