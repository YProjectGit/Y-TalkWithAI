# 6. TextToImage — テキスト → 画像生成（概要）

> **現状**: フォルダと概要のみ。シーン・スクリプトは未実装です。  
> シリーズ全体の位置づけ → [Docs/demo-series-overview.md](../../Docs/demo-series-overview.md)

## このデモで学べること（予定）

- テキスト（プロンプト）を画像生成 API / モデルに送る流れ
- 返ってきた画像データを Unity のテクスチャとして表示する流れ
- これまでの「テキスト／音声で返す」とは違う、**画像が出てくる**出力の扱い方

## 処理の骨格

```text
ユーザー入力（テキスト／プロンプト）
  → 画像生成（Image）
  → 画面に表示（RawImage など）
```

`1. TextChat` がテキストを返すのに対し、ここでは **絵を返す** のがポイントです。音声パイプライン（TTS）は使いません。

## 主要スクリプトの読み方（実装後）

入口スクリプトを上から読む想定の流れです。

1. APIキー読込・UI 初期化
2. プロンプト送信（リクエスト JSON 組み立て）
3. 画像バイト列（または URL）の受信
4. `Texture2D` 化して UI に表示
5.（教材向け）Status / リクエスト / メタ情報の可視化

## 改変のヒント（実装後に触るとよい箇所）

- プロンプトの書き方（短い指示 vs 具体的な描写）
- アスペクト比・枚数など、API が持つ生成オプション
- 生成結果を保存する／しない

## まだやらないこと

- 入力画像を渡して加工する（→ `7. ImageToImage`）
- 生成結果を声で説明する（必要なら 4 / 5 の発想と組み合わせる実験）
