# 5. VisionToSpeech — カメラ画像 → 音声で返答（概要）

> **現状**: フォルダと概要のみ。シーン・スクリプトは未実装です。  
> シリーズ全体の位置づけ → [Docs/demo-series-overview.md](../../Docs/demo-series-overview.md)

## このデモで学べること（予定）

- WebCam などから画像（フレーム）を取得する流れ
- 画像を Vision 対応の LLM に送り、「何が見えるか／どう答えるか」のテキストを得る流れ
- 返答テキストを TTS で音声にして再生する流れ

## 処理の骨格

```text
カメラ入力（画像）
  → Vision LLM（解釈・返答テキスト）
  → TTS（音声データ）
  → スピーカー再生
```

マイクは使いません。**見たもの**を LLM に渡し、**声で説明する**デモです。TTS〜再生は `3. TextToSpeech` と同型です。

## 主要スクリプトの読み方（実装後）

入口スクリプトを上から読む想定の流れです。

1. APIキー読込・カメラ起動（プレビュー表示）
2. シャッター（または定期キャプチャ）で静止画化
3. 画像を LLM リクエストに載せて送信（必要なら短いテキスト指示も添える）
4. 返答テキストの抽出・表示
5. TTS → 再生
6.（教材向け）送った指示・返答テキスト・Status の可視化

## 改変のヒント（実装後に触るとよい箇所）

- 画像と一緒に送る指示文（「色を一言で」「安全かどうか」など）
- キャプチャ解像度（重い／粗いのトレードオフ）
- プレビュー UI の大きさ・ミラー表示
- （発展）返答を JSON にしてラベル表示する（`2. StructuredOutput` の復習）

## まだやらないこと

- マイク経由の会話（→ `4. SpeechToSpeech`）
- テキストのみのチャット（→ `1. TextChat`）
- 画面キャプチャ入力（→ `6. ScreenToSpeech`）
