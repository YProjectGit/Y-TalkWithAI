# 3. TextToSpeech — テキスト送信 → 音声で返答（概要）

> **現状**: フォルダと概要のみ。シーン・スクリプトは未実装です。  
> シリーズ全体の位置づけ → [Docs/demo-series-overview.md](../../Docs/demo-series-overview.md)

## このデモで学べること（予定）

- テキストを LLM に送り、返答テキストを得る流れ（`1. TextChat` の延長）
- 返答テキストを TTS（Text-to-Speech）で音声データに変換する流れ
- Unity 上で音声を再生するまでの一連のパイプライン

## 処理の骨格

```text
ユーザー入力（テキスト）
  → LLM（返答テキスト）
  → TTS（音声データ）
  → スピーカー再生
```

TextChat が「テキストで返す」ところまでだったのに対し、ここでは **最後に声で返す** のがポイントです。

## 主要スクリプトの読み方（実装後）

入口スクリプトを上から読む想定の流れです。

1. APIキー読込・UI 初期化
2. テキスト送信 → LLM 呼び出し
3. 返答テキストの抽出・表示
4. TTS リクエスト → 音声バイト列の受信
5. `AudioClip` 化して再生
6.（教材向け）Status / 中間テキスト / 生データの可視化

## 改変のヒント（実装後に触るとよい箇所）

- LLM のモデル名 / プロンプトの一言
- TTS の声・言語・話速（API が対応していれば）
- 再生前にテキストも画面に出す／出さない

## まだやらないこと

- カメラ画像（→ `5. VisionToSpeech`）
- 構造化出力で UI を動かす（→ `2. StructuredOutput`）
