## このデモで学べること（予定）

- **画像生成**  
  テキスト（プロンプト）から画像を作る
- **画像の受け取りと表示**  
  返ってきた画像データを Unity 上で見せる
- **画像という出力**  
  テキストや音声とは違う、ビジュアルな戻り値の扱い

## 処理の骨格

```text
ユーザー入力（テキスト／プロンプト）
  → 画像生成（Image）
  → 画面に表示（RawImage など）
```

`1A.TextToText` がテキストを返すのに対し、ここでは **絵を返す** のがポイントです。音声パイプライン（TTS）は使いません。
