# 2. StructuredOutput — 決まった形（JSON）で返して Unity を動かす（概要）

## このデモで学べること（予定）

- LLM に **自由文ではなく、決まった形（JSON など）** で返してもらう流れ
- 返答をパースして、Unity 側の UI やパラメータを更新する流れ
- `1. TextChat` の「会話して表示する」から一歩進み、**返事でアプリを動かす**こと

このワークショップの柱のひとつです（構造化出力）。

## 処理の骨格

```text
ユーザー入力（テキスト）
  → LLM（構造化された返答：JSON など）
  → パース
  → UI / 色 / 数値 / Prefab などを更新
```

TextChat がテキストを吹き出しに出すのに対し、ここでは **形の決まったデータとして受け取り、画面やオブジェクトに反映する** のがポイントです。

## 事前準備（実装後に使う想定）

## 主要スクリプトの読み方（実装後）

入口スクリプトを上から読む想定の流れです。

1. APIキー読込・UI 初期化
2. 「この形で返して」という指示（スキーマ／例示）をリクエストに含める
3. LLM 呼び出し → 生 JSON の表示（可視化）
4. パースしてフィールドを取り出す
5. UI やオブジェクトへ反映（例: 色・ラベル・個数）
6. パース失敗時の扱い（ログ／画面表示）

## 改変のヒント（実装後に触るとよい箇所）

- 返すフィールドを増やす（色だけ → 色＋大きさ＋名前 など）
- 反映先を変える（Text → Image の色 → 3D オブジェクト）
- スキーマを崩した返答が来たときのメッセージ

## まだやらないこと

- 音声入出力（→ `3. TextToSpeech` / `4. SpeechToSpeech`）
- 画像入出力（→ `5` 以降）
- Function Calling / Tool Use（別デモ候補。ここでは「JSON を受け取って自分で適用する」に絞る）
